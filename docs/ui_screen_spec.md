# UI 화면 명세

레퍼런스의 세로형 패널, 먹색 배경, 황동 포인트, 한지 질감을 독립적으로 재해석한다.

| 화면 | 구성 |
|---|---|
| 시작 | 붓글씨풍 로고, 새 강호, 이어하기, 안내 |
| 강호 | 상단 상태, 현재 적, 체력 바, 전투 로그, 자동전투, 지역/보스 버튼 |
| 지역 | 7개 지역 카드, 권장 레벨, 진행도, 잠금 |
| 무인 | 초상 대체 문장, 경지·능력치, 포인트 투자, 장비 요약 |
| 행낭 | 장비 카드, 현재 장비 비교, 장착/잠금/분해 |
| 무도 | 무공 슬롯/숙련도와 경맥 분기 노드 |
| 기연 | 짧은 서사, 두 선택지, 즉시 결과 |
| 보스 | 이름·체력·로그·보상 패널 |
| 강호록 | 지역/보스/무공/기연 기록, 엔딩 상태 |

하단 탭은 강호, 무인, 무도, 행낭, 강호록으로 고정한다. 좁은 웹 창에서도 최대 폭 520px의 모바일 프레임을 유지한다.
