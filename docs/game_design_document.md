# 게임 디자인 문서

## 핵심 루프
사냥 지역 선택 → 자동 전투 → 경험치·은자·장비 획득 → 장비/능력치/무공/경맥 조정 → 보스 격파 → 다음 지역 해금의 반복이다. 전투 중 드문 기연은 선택에 따라 보상, 위험 전투, 능력 변화로 이어진다.

## 지역과 완주
낙양 외곽, 청죽림, 흑풍채, 산서대로, 운남 독림, 혈음곡, 천마봉 순으로 진행한다. 각 지역 보스를 이기면 다음 지역이 열리고, 천마봉의 천마 잔영 승리 후 엔딩을 표시한다.

## 성장
레벨업마다 능력치 3, 경맥점 1을 준다. 근력·근골·민첩·오성·기혈·내력이 공격, 방어, 회피, 치명, 생명, 내력에 반영된다. 경지는 삼류→이류→일류→절정이며 레벨, 이전 보스, 무공 숙련 조건으로 돌파한다.

## 장비·무공·경맥
8 장비 슬롯과 4등급 장비, 무공 5슬롯(초식 3/보조/심법), 90개 내외 경맥 노드의 분기 빌드를 제공한다. 알파에서는 모든 무공/경맥 데이터가 존재하며 초기 노드와 무공부터 차례로 해금한다.

## 엔딩
천마 잔영을 쓰러뜨리면 강호의 새 장을 여는 짧은 엔딩과 누적 행적을 보여 주며 저장은 계속 가능하다.
