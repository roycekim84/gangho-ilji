# 《강호일지》 시안 대비 출시 전 완성도 평가

평가 기준일: 2026-08-28  
비교 기준: 첨부된 10면 UI 콘셉트 시안, 현재 GitHub Pages 알파

## 종합 판단

현재 버전은 **출시 전 알파 기준 약 74%**의 완성도다.

- 플레이 가능한 기능 완성도: **88%**
- 화면 구조·정보 위계: **82%**
- 시각 아트·연출 완성도: **62%**
- 반응형·접근성·검증: **80%**

출시 가능한 작은 완성 게임의 핵심 루프는 이미 성립한다. 다만 첨부 시안과 나란히 놓았을 때 ‘상용 게임 시안 수준’으로 보이려면 화면별 전용 아트, 보상 연출, 상태 전환 모션, 텍스트 편집을 추가해야 한다.

| 항목 | 현재 구현 | 평가 |

| 세로형 모바일 구조 | 중앙 제한 폭 + 하단 5탭 | 시안 구조와 일치 |
| 강호 메인 | 상태→지역→VS→로그→자동전투 | 핵심 정보 순서 일치 |

| 기연/강호록 | 선택지, 지역 배경, 기록 탭 | 알파 범위 충족 |

## 가장 큰 차이

### 1. 아트의 밀도와 독립성

시안은 화면마다 주인공·적·지역·아이템 이미지가 강하게 분리되어 있다. 현재는 지역/보스/장비 핵심 이미지는 확보했지만, 무공 목록·강호록·빈 상태·일부 적 배지는 공용 아이콘과 반복 아트 비중이 높다.

영향도: 매우 큼  
보완: 화면별 전용 키아트 8~12종, 비급 계열별 표지 4종, 강호록 질감/문양 세트 추가

### 2. 상태 변화 연출

시안은 보상 팝업, 보스 승리, 장비 교체가 하나의 장면처럼 보인다. 현재는 색상·아이콘·텍스트 피드백은 있으나 대부분 즉시 상태 변경이다.

영향도: 큼  
보완: 300ms 프레임 강조, 장비 교체 비교 플래시, 보스 승리 보상 패널, 기연 결과 전환

### 3. 텍스트 편집 품질

현재 문구는 기능 전달에는 충분하다. 시안 수준을 위해서는 로그와 지역 설명을 더 짧고 강한 무협 문장으로 다듬고, 숫자 표기 규칙을 통일해야 한다.

영향도: 중간  
보완: 전투 로그 30~40개 문장 패턴, 보상/피해/치명타 용어집, 지역별 한 줄 카피

### 4. 화면별 세부 위계

큰 구조는 맞지만 장비 상세·기연·강호록 일부는 시안보다 버튼과 카드의 상태 구분이 약하다. 공통 토큰은 마련되어 있으므로 화면별 1회 추가 정리가 필요하다.

- **현재 상태**: 외부 테스트 가능한 플레이어블 알파
