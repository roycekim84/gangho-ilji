# 콘텐츠 계획

## 지역·보스
1. 낙양 외곽 — 들개·산적·흑의 자객 / 철면 도적
2. 청죽림 — 죽엽승·독사·녹림 궁수 / 청죽 검객
3. 흑풍채 — 채찍수·도적·투척수 / 흑풍 방주
4. 산서대로 — 마적·밀수꾼·창수 / 황토 창왕
5. 운남 독림 — 독충·묘족 전사·독사술사 / 독안 무녀
6. 혈음곡 — 혈교도·음귀·혈도객 / 혈음 노인
7. 천마봉 — 마교 정예·암영·천마 친위 / 천마 잔영

20종 일반 적은 지역마다 2~3종을 돌려 쓰며, 7 보스를 데이터화한다. 24무공은 검·도·권·암기·심법 계열 각 4~5개로 구성한다. 장비는 8슬롯×범품/양품/명품과 보물 세트로 50종 이상, 명병/보물은 10종, 기연은 지역별 2~3개를 포함한다.
