# 전투 로그 용어집

전투 로그와 보상 모달의 표준 표현을 정의한다.

| 의미 | 표준 표현 | 사용 예 |
| --- | --- | --- |
| 일반 공격 | `반격` | 독고진의 반격, 284 피해. |
| 적 공격 | `공격` | 흑호방 제자의 공격, 36 피해. |
| 무공 발동 | `발동` | 낙엽검법 발동! 420 피해. |
| 회피 | `공격을 흘려냈습니다` | 독고진이(가) 공격을 흘려냈습니다. |
| 치명타 | `치명타!` | 피해 로그 직전에 표시 |
| 적 처치 | `격파` | 흑호방 제자 격파! |
| 보스 처치 | `을 꺾고 새 길을 열었습니다` | 처치와 해금 동시 안내 |
| 경험치·은자 | `경험치 +N, 은자 +N` | 숫자는 천 단위 구분 |
| 장비 획득 | `등급 장비 「이름」을 얻었습니다` | 등급 색상과 함께 강조 |
| 경지 변화 | `경지 돌파` | 이류·일류·절정으로 통일 |

표현 원칙: 피해·치명타는 짧게, 획득·격파·돌파는 완료 색상으로 표시하며 `피해`, `경험치`, `은자`, `경맥점` 단위는 생략하지 않는다.
