- 콘텐츠 데이터: 7 지역, 21 일반 적 표기, 7 보스, 24 무공, 20 기연, 90 경맥 노드 정의를 추가했다.

## 2026-08-26 — 강호 메인 화면 1차 리디자인
- 자동 전투 계산/저장/드랍 등 기존 Game 로직은 변경하지 않고 강호 메인 전용 UI만 교체했다.
- 캐릭터 상태를 초상·경지·레벨·은자·HP·내력 정보 패널로 재구성했다.
- 지역 진행도, VS 전투 상황, 로그 색상 계층(피해/치명타/회피/획득), 자동전투 상태를 첫 viewport에 배치했다.
- Material NavigationBar를 무협풍 커스텀 하단 탭으로 대체하고, 각 패널의 테두리/색상/타이포그래피 토큰을 일관화했다.
- GitHub Pages 실제 페이지에서 390px 근처 모바일 프레임과 데스크톱 중앙 정렬을 확인했다.

## 2026-08-26 — 무인 화면 1차 리디자인
- 기존 Game 상태와 능력치 투자 동작을 유지한 채 무인 화면 표시 위젯을 교체했다.
- 프로필 패널, 수련 게이지, 능력치 2열 투자 그리드, 전투 능력 요약, 8슬롯 장비 요약을 추가했다.
- 강호 메인과 같은 먹색/한지색/황동 토큰과 각진 서책형 패널을 재사용했다.

## 2026-08-26 — 행낭 화면 1차 리디자인
- 기존 장착/잠금/분해 로직은 유지하고 행낭 전용 UI를 교체했다.
- 슬롯 현황 헤더, 장비 분류 필터, 등급별 색상, 현재 장비 대비 전투 점수 비교를 추가했다.
- 장비 액션을 각 카드 하단에 정리해 모바일에서 장착/잠금/분해 동작을 빠르게 찾을 수 있게 했다.

## 2026-08-26 — 무도 화면 1차 리디자인
- 기존 무공 장착/해제와 경맥 이동 동작을 유지한 채 무도 허브를 교체했다.
- 장착 슬롯 5개, 숙련도, 무공 위력, 보유 무공의 등급/쿨다운/습득 상태를 한 화면에 정리했다.
- 경맥도 진입을 상단 액션으로 통합해 무공과 빌드 화면을 빠르게 오갈 수 있게 했다.
## 2026-08-26 — 강호록 화면 1차 리디자인
- 기존 기록 데이터를 유지한 채 강호록을 서책형 기록 보관소 구조로 교체했다.
- 행적·무공록·병기록·인물록·기연록을 탭으로 분리하고 진행도, 습득 상태, 보스 기록을 한눈에 표시했다.
- 전투/저장 로직은 건드리지 않고 `Game`의 현재 상태만 읽어 기록 화면을 구성했다.
## 2026-08-26 — 기연 이벤트 오버레이 개선
- 기연의 제목, 상황 설명, 선택지 영역을 분리해 읽기 흐름을 개선했다.
- 선택지 번호와 무협 서책형 테두리를 추가했으며 기존 `game.resolve` 결과 처리는 그대로 사용한다.
