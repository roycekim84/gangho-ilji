# 아트 가이드

- 기준 분위기: 먹색·짙은 갈색·한지·목재·황동·절제된 적색의 고전 무협 서책.
- 신규 아트는 기존 지역/보스/주인공 이미지의 명암과 질감에 맞추고, 네온·현대 SaaS 카드 느낌을 피한다.
- 장비·캐릭터·비급은 가능한 한 슬롯/계열 전용 아트를 사용한다. fallback은 누락 시에만 허용한다.
- 아이콘은 48px에서도 실루엣이 읽히고, 얇은 황동 프레임과 어두운 여백을 갖춘다.
- ImageGen 사용 시 원본 로고·문구·워터마크를 포함하지 않는 독립 이미지를 생성하고, 생성 프롬프트와 파일 매핑을 개발 로그에 남긴다.
- 이미지 생성이 불가능하면 저품질 임시 이미지를 만들지 말고 필요한 규격·프롬프트·TODO를 기록한다.
- 화면별 색상은 기능 의미를 유지한다: 금색=핵심/보상, 적색=위험/치명, 녹색=획득/완료, 청록=회피/방어.
