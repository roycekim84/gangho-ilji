# 게임 품질 가이드

- 출시 문서나 마케팅보다 실제 플레이 완성도를 우선한다.
- 빈 화면, 의미 없는 임시 문구, 범용 placeholder를 최종 상태로 남기지 않는다.
- 자동 전투→드랍→장착→성장→다음 지역 흐름을 항상 처음부터 끝까지 확인한다.
- 새 기능은 진입 화면뿐 아니라 결과·저장·복귀·다음 화면 연결까지 검토한다.
- 정보 위계, 가독성, 터치 영역, 피드백 타이밍, 오류 복구를 함께 평가한다.
- 기존 동작 보존에 그치지 않고 플레이어가 체감하는 명확성·밀도·연출을 개선한다.
- 기능 변경 후 테스트·analyze·웹 빌드와 작은 화면 QA를 완료해야 한다.
