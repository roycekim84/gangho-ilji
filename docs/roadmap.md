# 강호일지 통합 로드맵

기준: 로컬 저장 기반 세로형 무협 방치형 RPG의 처음부터 엔딩까지 플레이 가능한 알파.

## Phase 0 — 기반 문서·골격 (완료)
- Flutter Web/모바일 골격, JSON 콘텐츠, 로컬 저장, 기본 라우팅과 디자인 토큰.

## Phase 1 — 플레이 루프 (완료)
- 자동 전투, 7지역/보스 진행, 장비 드랍·장착, 능력치·경지·오프라인 보상.
- 테스트로 전투·저장·진행·경계값을 고정.

## Phase 2 — 화면 정보 구조 (완료)
- 10개 핵심 화면의 패널 위계, 하단 탭, 상태 게이지, 지역·보스·엔딩 흐름.

## Phase 3 — 전용 아트와 연출 (진행 중)
- 완료: 지역/보스/주인공/적 아트, 비급 5계열 표지, 강호록 종이·도장, 주요 전환 피드백.
- 진행: 8장비 슬롯 전용 아트 확장(신발·손·허리띠·목걸이·옥패 완료).
- 진행: 등급별 프레임 대비·미세 광택 점검 완료, 화면별 시각 QA 진행.
- 완료 조건: 핵심 카드에 범용 placeholder가 남지 않고 상태 변화가 시각·텍스트 2가지 이상으로 피드백됨.

## Phase 4 — 텍스트·밸런스·접근성 (예정)
- 전투 로그 용어집, 지역/보스/기연 문장 편집, 숫자 규칙 통일, 44px 터치와 키보드 포커스 점검.

## Phase 5 — 릴리스 후보 (예정)
- 320×700·390×844·데스크톱 웹 QA, 저장 마이그레이션/복구, 전체 회귀 테스트, Pages 배포 smoke test.

우선순위는 현재 Phase의 미완료 P0부터 처리하며, 기능 추가보다 실제 플레이 흐름과 시안 수준의 완성도를 우선한다.
