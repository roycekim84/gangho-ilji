# 시스템 설계

## 상태와 저장
`GameController`가 콘텐츠와 `GameSave`를 소유한다. 저장은 로컬 JSON이며 변경 후 즉시 저장한다. 앱 재개 시 마지막 접속 시간을 기준으로 최대 8시간의 오프라인 보상을 계산한다.

## 전투
1초 틱마다 플레이어와 적이 서로 피해를 준다. 공격력, 방어, 치명, 회피, 장착 무공의 배율/쿨다운을 반영하며 최근 로그 80줄을 화면에 유지한다. 처치 시 경험치·은자·진행도·확률 드랍을 지급하고 다음 적을 생성한다.

## 드랍과 장비
지역별 드랍 등급을 기준으로 슬롯, 품질, 기본 공격/방어, 보조 옵션을 난수 생성한다. 장착 시 같은 슬롯과 비교하고 기존 장비는 가방으로 이동한다. 잠긴 장비는 분해할 수 없다.

## 기연
사냥 처치마다 낮은 확률로 현재 지역에 맞는 미해결 이벤트를 큐에 넣고 전투를 잠시 멈춘다. 선택 결과는 은자, 경험치, 능력치, 장비 또는 피해로 적용한다.

## 보스와 해금
보스 전투는 일반 사냥과 같은 계산기에서 적 스펙만 바꾼 형태다. 승리 시 지역 완료, 다음 지역 해금, 돌파 조건 갱신을 처리한다.
