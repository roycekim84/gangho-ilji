# 강호일지 — 로컬 완성판 알파

## 게임 개요
`강호일지`는 무명 무인이 강호의 일곱 고을을 지나 천마봉의 주인을 쓰러뜨리는 세로형 텍스트 방치 RPG다. 자동 전투의 결과를 장비, 무공, 경맥, 능력치 세팅으로 바꾸는 것이 중심 재미다.

## 목표
- 신규 강호 생성부터 최종 보스와 엔딩까지 한 기기에서 완주한다.
- 웹과 모바일 세로 화면에서 같은 저장 기반 플레이를 지원한다.
- 수치와 로그가 명확한 짧은 성장 루프를 제공한다.

## 기술 스택
- Flutter / Dart, Material 3 기반 커스텀 UI
- `shared_preferences` + JSON 문자열 저장
- `provider` 상태 관리, 기본 Navigator/탭 전환
- JSON 콘텐츠 데이터(`assets/data`)와 Dart 모델 로더

## 범위와 제외
7지역, 자동전투, 드랍·장착, 능력치, 경맥, 24무공, 기연, 오프라인 보상, 보스, 엔딩을 포함한다. 로그인·서버·결제·광고·PVP·거래·길드·랭킹은 포함하지 않는다.
